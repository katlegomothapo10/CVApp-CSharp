# CVApp-CSharp

https://localhost:7085/

This is a web based CV or Resume application developed for ICE 1 using ASP.NET Core MVC. The application displays professional information in a clean and modern format, providing an online presence for individuals to showcase their qualifications and experience.

Purpose of the Application

The application serves as an online CV that effectively showcases personal information and contact details, comprehensive work experience history with company names and dates, educational background with qualifications and institutions, technical and soft skills with proficiency levels, and portfolio projects with descriptions and technologies used.


The CV application features a professional layout with responsive design that adapts to different screen sizes including desktop, tablet, and mobile devices. It includes dedicated sections for personal information, work experience displayed in timeline format, educational qualifications, categorized skills, and portfolio projects. The interface uses a clean design with gradient accents and provides easy readability of all content.


The application is built using ASP.NET Core MVC framework with .NET 6. The frontend utilizes HTML5, CSS3, and Bootstrap 5 for responsive styling. Font Awesome 6 is used for icons throughout the interface. The backend logic is written in C# programming language.


The project follows standard MVC architecture with Controllers handling the application logic, Models defining the data structures for CV content including personal information, experience, education, skills, and projects, and Views containing the user interface templates for displaying the CV. The main CV data is populated through a sample data method in the controller.


To run the application locally, clone the repository from GitHub, open the project in Visual Studio, restore the necessary NuGet packages, build the solution, and run the application by pressing F5. The CV can then be viewed by navigating to https colon slash slash localhost colon 5001 in your web browser.
